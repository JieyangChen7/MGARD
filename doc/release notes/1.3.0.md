# MGARD 1.3.0 Release Notes

**Released:** September 30, 2022

## Added
* ***MGARD-X***: portable compression for CPU and GPU.
  * Support for CPU (serial), CPU (multi-threaded), NVIDIA GPUs, AMD GPUs, and Intel GPUs.
  * Self-describing format.
  * Automatic domain decomposition for handling large datasets.
  * Automatic parallel compression across multiple GPUs.
  * High-level compression API for automatic metadata management and domain decomposition.
  * Low-level compression API for full control over the compression process on devices.
* ***MDR-X***: portable multi-precision data refactoring on CPU and GPU.
  * Modular design allowing flexible control over the data refactoring and reconstruction process.
  * Same portability as MGARD-X.
