# MGARD 1.0.0 Release Notes

**Released:** September 30, 2021

## Added
* Self-describing command-line executable.
* Support for 'flat' datasets.
* A command line interface.
* High-level APIs for easier integration with user programs and I/O libraries.
* Support for choosing different lossless compressors.
* Self-describing decompression API.
* Examples.

## Changed
* Migrated the continuous integration setup.
* Improved CPU compression and decompression speed (iterator optimizations, index precomputation, shuffled values for better memory access patterns).
* Parallelized operator application with OpenMP.
* Improved quantization speed.
* Improved the performance of the multilevel decomposition.

## Fixed
* Fixed several bugs in the multilevel decomposition.
